# 砚山：可视化写作画布

日期：2026-11-15。承接用户“继续执行操作和实现”的授权，本轮直接实现，不再次要求选择工作流。

本轮聚焦文章和笔记的组件编辑。保留现有默认源码入口，新增可切换的画布，支持标题、段落、图片、代码、公式、提示卡、Mermaid 和原始 Markdown 块。画布延续宣纸、墨绿、朱砂与细分隔线；桌面使用组件区与阅读预览，小屏单列。组件提供拖拽手柄、键盘排序和明确的移动按钮。

选择保守的 Markdown 分块方案：Markdown 是唯一持久化正文，块 ID 和分段只是编辑会话状态。不新增第二份可写 blocks 数据；此点替代上一条消息中“新增 blocks 字段”的初步设想。打开、切换画布但不修改时必须逐字保留原文，包括空白、代码、链接定义和未知语法。解析器发现无法逐字复原时，将整个片段保留为原始块。编辑或排序只规范必要的块间分隔，不对整篇文章重新排版。

相比引入完整富文本框架，该方案能直接复用当前 API、保存版本、快照、备份、资源鉴权和多平台交付；代价是它是组件编排编辑器，并非任意富文本的所见即所得编辑器。相比继续只做源码插入按钮，它能直接调整文章结构并在块内预览公式和图解。

公式使用 KaTeX 本地预览，Mermaid 按需严格模式渲染。代码块使用足够长的围栏避免正文中的反引号截断。未知语法、表格、链接定义、HTML、列表保留源码编辑。图片通过现有资源上传和关联进入文章。修改与排序写入同一个正文状态，继续适用未保存提示、版本冲突和快照恢复。

不在本轮宣称科研绘图、公式参数模型、Tiptap、嵌入式 draw.io、实际 AI 调用、PDF 批注或 LaTeX 编译完成。文章内 Mermaid 在画布预览；静态博客和第三方导出保留 Mermaid 围栏源码，图形公开导出留待后续渲染器。

验收：所有现有文章分块后原样拼接；围栏、未知语法和公式可保留；添加、编辑、排序、复制和删除组件可撤销；保存后重开内容一致；旧文章不自动变更；鼠标拖拽、键盘和小屏移动可用；资源引用及版本冲突沿用已有验证。维护 README 和能力说明，完成构建、类型检查及浏览器流程后同步双远端。
