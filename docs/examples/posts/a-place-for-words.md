这是一篇用于预览博客排版的示例文章。你可以在本地创作台删除它，换成自己的第一篇文字。

## 为什么还要有一个独立博客

当内容散落在不同平台，我们往往记得发表时的心情，却忘记了它究竟被放在哪里。

独立博客像一间可以自己布置的小屋。没有人规定窗户该开在哪个方向，也没有人要求每一篇文字都必须得到即时的回应。你可以把长文放在桌上，把一闪而过的念头夹进书里。

> 写作不是为了证明走了多远，而是让自己知道，曾经认真地走过。

## 从一份 Markdown 开始

内容应该尽量简单、可迁移。纯文本文件的好处，是即使有一天更换了工具，文字仍然握在自己手里。

```markdown
---
title: 我的第一篇文章
date: 2026-11-14
category: 随笔手记
tags: [记录]
---

今天，给文字一个自己的家。
```

### 把写作和发布分开

写作时只关心内容。发布时，再检查摘要、封面、来源链接和目标账号。这一点点边界，能让整个过程更从容。

1. 在本地写下初稿，暂时不追求完美。
2. 预览长段落、图片与代码的排版。
3. 选择公开发布的文章，再推送到仓库。
4. 根据需要，把同一份内容分发到其他平台。

## 给未来留一点余地

一个博客不需要一开始就装进所有功能。清晰的导航、舒服的字号、稳定的链接，往往比热闹的动效更能陪伴一个人长期写下去。

| 我在意的事 | 可以做的小事 |
| --- | --- |
| 内容属于自己 | 保留 Markdown 与本地图片 |
| 阅读舒服 | 控制行宽、行距和对比度 |
| 能被找到 | 使用稳定链接与全文搜索 |
| 能继续写下去 | 简化保存和发布流程 |

愿这里成为一个可以慢慢生长的地方。
