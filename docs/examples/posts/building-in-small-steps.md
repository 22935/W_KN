这是一篇项目初始示例文章。

## 从一个完整的路径开始

一个功能不只是一个按钮。输入从哪里来，执行过程中发生什么，失败时如何恢复，完成后能看到什么，这些都属于同一个功能。

先把一条路径做完整，再逐步增加分支，比同时铺开所有界面更容易验证价值。

## 让结果可以检查

本地构建成功与网站已经上线，是不同的结果。文章保存成功与平台发布成功，也需要不同的证据。准确表达进度，是可靠工具的一部分。

```javascript
const status = {
  saved: '本地草稿已保存',
  prepared: '分发文件已生成，等待平台确认',
  published: '已验证公开文章地址',
};
```
