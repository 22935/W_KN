ONE VOICE, MANY PLACES

让好的内容，走得更远。

每个平台、每个账号，拥有独立的浏览器登录环境。

添加账号仅保存备注，不代表已登录。点击“打开登录窗口”，在独立 Chrome / Chromium 窗口中登录对应账号。同一平台可以添加多个账号。

关于平台兼容性

浏览器辅助填入 CSDN、掘金、知乎编辑器属于实验能力，平台改版或登录限制可能需要人工接续。微信公众号提供独立窗口与交付文件。所有平台的最终提交和审核在平台完成，工作台不会误报自动发布成功。

也可使用开源 Wechatsync 文章同步助手 ↗ 继续分发。不同版本兼容性需在本机验证，同平台多账号建议使用本工作台的独立会话窗口。
